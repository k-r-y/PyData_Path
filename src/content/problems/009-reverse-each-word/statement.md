Given a single-line record `text`, reverse the characters inside each space-delimited word while preserving word order and exact space separators (`' '`).

Write `reverse_each_word(text: str) -> str`.

### Example
- `"SQL log ready"` -> `"LQS gol ydaer"`
- `"ab  cd"` -> `"ba  dc"` (two spaces remain two spaces)
