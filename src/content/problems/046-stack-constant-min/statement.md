Design a stack supporting `O(1)` worst-case minimum queries.

Implement `class MinStack` with:
- `push(val)`: pushes `val` onto the stack.
- `pop()`: removes and returns the top value (raises `IndexError` if empty).
- `top()`: returns the top value without removing (raises `IndexError` if empty).
- `get_min()`: returns the minimum value currently stored in `O(1)` time (raises `IndexError` if empty).
